# Eyob Tsige Terefe - Personal Portfolio

Personal and professional portfolio website for **Eyob Tsige Terefe**. 

## Project Overview
This project serves as the digital presence for Eyob Tsige Terefe, highlighting his vast experience and contributions in education, media, and professional leadership.

## Key Features
- **Education and Academic Background**
- **Professional Leadership**
- **SEMAY Multimedia and Promotion**
- **Union Academy**
- **Radio and Television Programs**
- **Proverbs & Wisdom Carousel**: A bilingual (Amharic & English) swipeable card carousel showcasing traditional proverbs with a premium black-and-gold design.

## Tech Stack
- Next.js (React Framework)
- TypeScript
- Tailwind CSS

## Running Locally

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
